# Job Radar (cloud)

Daily fresher job, govt notification, exam date and scholarship finder for **@sreekar_polepalli** (AP & TS students).

- Page: https://sreekar-jobs.github.io/job-radar (add to iPhone home screen: Safari → Share → Add to Home Screen)
- Runs every day at 09:00 IST. **Search now** = Actions → "Job Radar daily search" → Run workflow.
- Only public job / news data. Every fact must be checked on the official site before posting.
- Source of truth for the code: the laptop (Video-Studio/tools/job_radar*.py); this repo is synced from there.
